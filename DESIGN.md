# EFL by Level design system

## Direction

A confident educational editorial system: clear enough for new English learners, distinctive enough to avoid a generic course-template appearance, and practical enough for teachers scanning quickly.

## Principles

1. **Two routes are always visible:** learn or teach.
2. **Level is a visual navigation system:** each CEFR stage has a stable accent.
3. **Typography creates personality:** Fraunces for human, editorial display; DM Sans for readable interface copy.
4. **Colour carries meaning:** navy for trust, blue for action, yellow for attention, level colours for progression.
5. **Cards are used only for selectable resources:** larger narratives use open editorial layouts.
6. **Motion supports orientation:** subtle reveal and progress animation, with reduced-motion support.

## Quality requirements

- keyboard-visible focus states
- minimum 44px interactive targets
- no grey text over saturated backgrounds
- mobile-first navigation and wrapping
- no decorative dependency on external images
- clear error, consent and empty-state copy
